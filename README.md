# NextGen API Template Forge

## Description
An API-driven CSS template customization platform that allows users to customize themes in real time and integrate them into web applications using unique API keys.

## Technologies Used
- React.js
- Vite
- Node.js
- Express.js
- REST APIs
- HTML5
- CSS3
- Tailwind CSS
- Git & GitHub

## Key Features
- Dynamic CSS generation
- Real-time template customization
- Live preview workspace
- API key-based template integration
- Multiple responsive templates
- User profile and template upload support
- AI-assisted prompt-based theme generation

## Project Structure
```
frontend/   → React frontend
backend/    → Express backend
```

## How to Run

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
